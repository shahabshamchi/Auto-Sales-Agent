AI-powered automated sales and support assistant for businesses.

This open-source project handles the entire customer journey:
- answering customer questions in chat
- explaining products and services
- collecting and sending financial documents (invoices, receipts, contracts)
- basic customer support and follow-ups

The goal is to provide a reusable, privacy-conscious assistant that companies can self-host and customize for their own sales and support workflows.

## 🛠 Tech Stack
- **AI Framework:** LangChain / Claude API
- **Backend:** Python (FastAPI)
- **Frontend:** Next.js (Tailwind CSS)
- **Database:** PostgreSQL / Supabase
- **Document Processing:** PyPDF2 / Pydantic
